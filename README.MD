# T20 Cricket Match Analytics & Machine Learning Pipeline

**Internship Program:** Virtual Data Science Explorer Internship  
**Platform:** YuvaIntern  
**Author:** SRIRAJ W.V.P.S  

## Project Overview
This repository contains the strategic plans, analytical frameworks, machine learning designs, and presentation reports for a 4-week hypothetical data science project. The project focuses on predicting first-innings total scores and estimating match win probabilities in T20 franchise cricket using Python workflows.

---

## Repository Structure

### Week 1: Data Science Project Planning and Strategy Design
* **Focus:** Defining project objectives, scope, methodology, tools, and a 35-hour timeline for T20 match score prediction.
* **Files:** `Week_1_Project_Plan.docx`, `Week_1_Project_Plan.json`

### Week 2: Exploratory Data Analysis (EDA) and Visualization Framework Design
* **Focus:** Data cleaning strategies, missing data imputation, outlier detection (IQR/Z-Score), and univariate/bivariate visualization strategies using Pandas, Matplotlib, and Seaborn.
* **Files:** `Week_2_EDA_Framework.docx`

### Week 3: Python-Based Machine Learning Model Development and Evaluation Plan
* **Focus:** Dual-output model architecture (XGBoost Regressor for score prediction & LightGBM Classifier for win outcome), hyperparameter tuning via Optuna, time-series validation, and FastAPI/Docker deployment.
* **Files:** `Week_3_ML_Model_Development_Plan.docx`

### Week 4: Comprehensive Data Science Report and Insights Presentation Plan
* **Focus:** Executive summary, mock-up charts, non-technical storytelling strategy, and operational recommendations for franchise stakeholders.
* **Files:** `Week_4_Final_Report_and_Insights.docx`
